# 과제 1: PEFT 기법 한 가지 돌려보고 비교표에서 위치 해석하기

3주차 실무 과제. 한국어 데이터셋에서 PEFT 기법 한 가지(예: LoRA)를 돌려보고,
제공된 비교표에서 자기 결과의 위치를 해석한다.

## 제출

- 경로: `assignments/week-03/<내 학번>/`
- 형태: 작업한 노트북(`.ipynb`) + 아래 **비교표 채운 버전**(마크다운 또는 셀 안 텍스트)
- 마감: 강의 사이트 과제 제출 문서를 따른다
- PR 제목: `[제출] 3주차 - <학번> <이름>`

## 조건 (반드시 명시할 것)

**도내 소규모 조직이 감당할 메모리·시간 예산**을 가정 조건으로 적는다.
예: "전용 GPU 없음, Colab 무료 티어, 30분 이내", "2GB 메모리 제한" 등.
이 예산 안에서 선택 근거를 대는 것이 채점 대상이다.

## 비교표

아래 표를 **자기 실측값으로 채워** 제출한다. 학습 파라미터 수는 노트북의
`print_trainable_parameters()` 출력을, 시간은 셀 실행 시간을 쓴다.

| 기법 | 학습 파라미터 수 | 전체 대비 비율 | GPU/런타임 | 학습 시간 | 평가 정확도 | 메모리 사용량 |
|---|---|---|---|---|---|---|
| 전체 미세조정 | (기준선) | 100% | | | | |
| LoRA (내 랭크 값) | | | | | | |
| (선택) 랭크 바꾼 결과 | | | | | | |

행을 늘려도 된다. 비교할 기법(DoRA, QLoRA 등)을 직접 돌려본 결과를 추가해도 좋다.

## 채점 기준 (3단계 부분점수)

| 단계 | 내용 | 비중 |
|---|---|---|
| 1 접근 설계 | 왜 이 방법을 선택했는지, 비교 대상은 무엇인지 | 40% |
| 2 동작 | 코드가 의도대로 실행되고 결과를 산출 | 40% |
| 3 성능·비교 | 결과를 기준선과 비교하고 해석 | 20% |

- 1단계만 성립해도 부분 점수를 받는다. 동작 실패를 이유로 0점 처리하지 않는다
- 성능 수치 자체보다 **비교의 타당성**을 본다. 절대 정확도 임계값을 정답 조건으로 두지 않는다
- 근거를 대는 표현은 자유다(미세조정/파인튜닝/fine-tuning 모두 정답)

## 답안에 들어가야 할 것

1. 가정한 메모리·시간 예산
2. 채운 비교표
3. 예산 안에서 선택한 기법과 그 근거 (왜 전체 미세조정이 아니라 PEFT인지 포함)
4. (있으면) 랭크·하이퍼파라미터 변경 시 달라진 점

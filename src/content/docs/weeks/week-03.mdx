효율적 미세조정의 원리와 변형

□ 이 주차가 놓이는 자리

- 2주차에서 학습 루프를 끝까지 돌려 봤다. 이번 주의 질문은 **"1.1억 개를 전부 다시 학습해야 하는가"** 다
- 답은 아니오다. 사전학습 모델은 동결해 두고, 아주 작은 추가 파라미터만 학습해도 목표 성능에 근접한다. 이것이 PEFT(Parameter-Efficient Fine-Tuning)다
- 이번 주 실습은 **과제 1**의 출발점이다. 과제 1은 PEFT 기법 하나를 돌려보고 비교표에서 위치를 해석하는 것이다

## 온라인 (2시수)

### 강의: PEFT 이론 - 저랭크 근사, LoRA·QLoRA

□ 전체 미세조정의 비용

- 2주차에 확인한 한국어 분류 모델의 전체 파라미터 수는 **112,922,882개**다. 전체 미세조정은 이 전부를 학습시킨다
- 학습 파라미터 하나에는 가중치 외에 그래디언트와 옵티마이저 상태가 붙는다. Adam 계열이면 모멘텀 두 벌이 더 필요해서, 학습 파라미터 수가 줄면 메모리는 그 몇 배로 준다
- 모델이 1.1억 개여서 이 정도다. 수십억 개짜리 모델을 전체 미세조정하려면 소규모 조직의 장비로는 애초에 손도 못 댄다

□ 저랭크 근사의 아이디어

- 미세조정이 가중치에 가하는 변화량(ΔW)은 **랭크가 낮은 행렬로 근사**할 수 있다는 것이 LoRA(arXiv:2106.09685)의 출발점이다
- 작은 수치 예. 768 x 768 가중치 행렬의 변화량을 통째로 학습하면 589,824개 파라미터다. 이를 두 행렬의 곱 ΔW = B·A (B는 768 x 4, A는 4 x 768)로 놓으면 학습할 것은 4 x 768 x 2 = **6,144개**. 1% 수준으로 줄어든다
- 직관: 사전학습 모델은 이미 잘 학습돼 있어서, 과제에 맞게 조정할 때 필요한 변화는 그리 복잡하지 않다. 낮은 랭크로도 그 변화를 거의 다 담을 수 있다

□ LoRA의 동작

- 원래 가중치 W는 **동결**한다. 옆에 A, B 두 저랭크 행렬을 붙이고 이것만 학습한다
- 순전파는 `W·x + (α/r)·B·A·x`. 스케일링 계수 α(보통 r의 2배)가 업데이트 크기를 조절한다
- 학습이 끝나면 B·A를 W에 합산할 수 있어서, **추론 때 추가 비용이 없다**. 이것이 어댑터 계열 중 LoRA가 널리 쓰이는 이유 하나다
- 실습 실측값(KoELECTRA base, query·value에 r=4 적용):

| 항목 | 값 |
|---|---|
| 전체 미세조정 학습 파라미터 | 112,922,882 (100%) |
| LoRA 학습 파라미터 | 739,586 (0.65%) |
| └ 어댑터(A·B) | 147,456 |
| └ 분류 헤드(새로 초기화된 부분) | 592,130 |

- 어댑터 자체는 15만 개 남짓이다. 분류 헤드는 원래 가중치가 없어 새로 학습해야 하므로 함께 열어 둔다

□ QLoRA

- QLoRA(arXiv:2305.14314)는 베이스 모델 가중치를 4비트로 양자화해 올려 놓고 그 위에 LoRA를 학습한다
- 파라미터 수는 LoRA와 같은데 **모델이 메모리에 올라가는 크기 자체**가 줄어든다. GPU 메모리가 작은 환경에서 큰 모델을 미세조정하는 실무 표준이 됐다
- 우리 실습 모델은 작아서 양자화 이득이 크지 않다. 개념과 언제 필요한지를 알아두는 것이 목적이다

### 학습활동

- 기법별(전체 미세조정 / LoRA / QLoRA) 학습 파라미터 수와 예상 메모리 사용량을 표로 정리하고, **어느 조건에서 무엇을 고를지** 선택 근거를 작성한다
- 기준은 숫자다. "가볍다"가 아니라 "학습 파라미터가 전체의 몇 퍼센트인가"로 말한다

## 대면 (1시수)

### 변형 기법의 차이 분석 - DoRA·VB-LoRA·WaveFT

□ 공통점과 갈림길

- 셋 다 LoRA의 "저랭크 업데이트" 골격 위에 있다. 갈림길은 **무엇을 더 쪼개거나 공유하는가**다

| 기법 | 바꾸는 것 | 한 줄 요약 | 출처 |
|---|---|---|---|
| DoRA | 가중치를 크기(magnitude)와 방향(direction)으로 분해 | 방향은 LoRA로, 크기는 별도 벡터로 학습해 전체 미세조정의 학습 패턴에 근접 | arXiv:2402.09353 (ICML 2024) |
| VB-LoRA | 어댑터를 층·모듈이 공유하는 벡터 은행에서 조합 | 전역 벡터 은행 하나를 두고 필요한 벡터만 골라 써서 파라미터를 극단적으로 절감 | arXiv:2405.15179 |
| WaveFT | 업데이트를 웨이블릿 변환 영역에서 학습 | 주파수 영역에서 희소한 업데이트를 배워 파라미터 수를 세밀하게 조절 (시각 모델 중심으로 제안) | arXiv:2505.12532 |

□ 비교할 때 보는 것

- 파라미터 수만 보지 않는다. **추론 시 추가 비용이 있는가**, **구현이 표준 라이브러리에 있는가**, **논문의 검증이 어떤 과제·모델에서 이뤄졌는가**를 함께 본다
- 예: LoRA와 DoRA는 병합이 가능해 추론 비용이 늘지 않지만, WaveFT는 제안된 지 얼마 되지 않아 텍스트 과제 검증이 제한적이다. "최신"과 "검증됨"은 다른 말이다

## 학습활동

**[이론]** 저랭크 근사가 왜 전체 미세조정을 대체할 수 있는지 **작은 수치 예로 확인**하고(768 x 768 → 6,144개 계산), 각 변형이 무엇을 바꾸는지 대조

**[구현]** 어댑터가 붙은 미세조정 코드를 받아 실행하고, 학습 파라미터 수가 전체 미세조정 대비 얼마나 줄었는지 출력값으로 확인. **랭크 값 하나를 바꿔** 변화를 관찰. r을 4에서 8로 올리면 어댑터 파라미터는 정확히 두 배가 된다. 성능이 두 배가 되는지는 출력으로 확인한다

**[실무]** 과제 1 - 한국어 데이터셋에서 **PEFT 기법 한 가지를 돌려보고** 제공된 비교표에서 자기 결과의 위치를 해석. **도내 소규모 조직이 감당할 메모리·시간 예산을 조건으로 명시**하고 그 안에서 선택 근거를 대는 것이 채점 대상 (3단계 부분점수 적용)

□ 실습 실측 참고값 (에폭 1회, NSMC 일부 2,400건 학습 기준)

- LoRA(r=4) 학습 파라미터 739,586개(전체의 0.65%), 평가 정확도 0.58 안팎(실행 환경에 따라 소폭 변동)
- 에폭 1회 맛보기 학습의 수치다. 에폭 수·랭크·데이터 양을 바꾸면 달라진다. **절대 정확도가 아니라 기준선 대비 위치를 읽는 것**이 이번 주의 요령이다

## 이번 주차

검색 결합 생성(RAG)의 구조

## 온라인 (2시수)

검색 결합 생성 이론 및 최신 연구 동향 강의 / 학습활동 - 제주 지역 공개 데이터로 소규모 색인을 만들고 검색 실패 사례 수집

## 대면 (1시수)

그래프 기반 검색 확장의 아이디어와 한계 분석

## 학습활동

**[이론]** 검색 실패가 생성 품질로 전파되는 경로. 검색 정확도와 최종 답 정확도가 어긋나는 조건

**[구현]** 색인-검색-재순위가 이어진 골격 코드를 받아 실행하고, **검색 단계 하나를 다른 방식으로 교체해** 최종 답이 어떻게 달라지는지 확인

**[실무]** 과제 3 - **제공된 골격으로** 제주데이터허브·관광 빅데이터 플랫폼 공개 데이터 색인을 만들고, 검색 실패 사례를 유형별로 분류해 원인 제시 (3단계 부분점수 적용) 〔데이터셋 실물은 개강 전 확인〕
